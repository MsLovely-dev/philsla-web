**Goal:** Verify and harden the existing Student Registration Maintenance feature without rebuilding it, correcting frontend route/navigation access so it matches the backend's authoritative `SYSTEM_ADMIN` + `DEPED_ADMIN` contract (a two-sided fix: revoke the `UNIVERSITY_ADMIN`/`ADMISSIONS_REVIEWER` frontend access that is currently reachable but always backend-rejected, and add the `DEPED_ADMIN` frontend access that currently has no path to a feature the backend already permits).
